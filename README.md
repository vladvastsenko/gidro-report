# ГидроОтчёт

Android-приложение для отчётов по контролю гидроизоляции.

Возможности первой версии:
- заполнение данных объекта, участка, инспектора и подрядчика;
- выбор результата осмотра;
- добавление фотографий;
- комментарий к каждому фото;
- создание PDF-отчёта;
- отправка PDF через WhatsApp, Telegram, почту и другие приложения.

## Сборка APK

APK собирается автоматически через GitHub Actions после каждого push в ветку `main`.

Готовый файл можно скачать во вкладке **Actions** → последний запуск → **Artifacts** → `gidro-report-debug-apk`.
